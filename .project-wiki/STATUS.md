# Project Status

Updated 2026-10-30. Current main includes TIP/PATSTAT candidate export, resumable translation code, two distinct 100-family samplers, and an isolated Perplexity Decider Flash v1.2 FP16 Kaggle pilot.

**Observed sample:** Uniform seeded sample over 232,636 original-English nonempty abstracts (238,824 source rows in all); 100 original-English families saved under `samples/random_100/`, with source text copied verbatim into `abstract_en`. The previously proposed 90/10 multilingual/CPC-stratified sampler is separate.

**Provisional labels provided 2026-10-30:** 100 unique sample IDs match the source list in order; 98 labeled not relevant, 0 labeled relevant, 2 marked for review. The label data were AI-assisted in another chat and have not been independently adjudicated. No precision/recall/F1 can currently be validated without positive labeled examples.

**GPU inference now confirmed for the 100-case pilot:** The user supplied `predictions.csv` with exactly 100 distinct DOCDB family IDs and finite probabilities in [0,1]; each ID matches the provisional English sample. Every prediction is 0 at the experimental 0.5 threshold, with maximum relevance probability 0.4362465 (unresolved family `93663023`). Against 98 provisional negative labels: 0 false positives, specificity 98/98. The other 2 annotations remain unresolved; there are no verified positives, so precision, recall and F1 are undefined. This is evidence of a completed single-GPU pilot, **not** production throughput or recall validity.

**First Kaggle run observed, 2026-10-30:** input, labels, Tesla T4 (14.6 GiB), and 9.10 GB model snapshot were detected/downloaded. Inference **did not start**: the pinned checkpoint requirements installed PyTorch with CUDA 13.0, while Kaggle's preinstalled TorchAudio was compiled for CUDA 12.8. This raised a TorchAudio runtime error inside the Transformers AutoProcessor import. **Fix committed but GPU rerun pending:** `kaggle/run.py` removes the unused optional TorchAudio library after installing requirements and checks AutoProcessor import in a fresh interpreter. The failure does not demonstrate model quality or CUDA FP16 compatibility.

**Next:** independently verify provisional labels, add independently adjudicated positive humanoid cases, calibrate/test without leakage, then benchmark production throughput. The current launcher deliberately uses one model on `cuda:0`; a production two-T4 option would use two independent FP16 replicas with disjoint patent shards and ID-verified merging, only after benchmarking memory and throughput. Translation, applicant/year corrections, landscaping, valuation, quadrant and recommendation remain separate work. Deadline: Sunday 20 December 2026.
