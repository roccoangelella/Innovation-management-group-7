# Open questions — 2026-10-31

- **OQ-001 (still open; partially implemented):** Which decision-model definition/prompt, acceptance threshold and evaluation procedure deliver defensible precision and recall? The FP16 Decider Flash Kaggle pilot has completed 100 English-family predictions on one T4; the negative-only evaluator is implemented. No confirmed positive cases exist, so positive-class behavior and threshold calibration are unverified. The independently provided AI-assisted labels for the 100 original-English random families contain 98 negatives, zero confirmed positives and 2 unresolved. A separately created 50/50 positive-enriched English challenge set with AI-authored provisional annotations is now available as one combined file `samples/humanoid_challenge_100/challenge_100_labeled.csv`, but it is not human-adjudicated or a representative prevalence sample. First FP16 Decider Flash inference on this challenge is now verified: 100 predictions, TP=50, TN=50, FP=FN=0 against AI-authored reference labels at threshold 0.5, with input hash matched. This is a development result, not independent human-ground-truth validity or representative deployment precision. Independent annotation verification and a distinct held-out calibration/test plan remain required before choosing a production threshold. A 2026-10-30 leakage/difficulty audit confirmed no direct label forwarding in the reviewed code, but found that a two-keyword baseline reaches 90% accuracy on the curated 50/50 benchmark; class selection and label dependence on humanoid terminology limit its discriminative validity. The earlier upload `predictions (1).csv` was from the random pilot, but a subsequent upload `predictions (2).csv` is conclusively from the challenge (input SHA matches). The 90/10 multilingual stratified benchmark remains separate. A distinct additional 40/60 `samples/humanoid_semantic_holdout_100/` dataset now removes overt humanoid terms but scores 81–86% using simple biped-related heuristics; it is still a purposive AI-provisional stress test. The precise boundary between humanoid-specific inventions and merely biped-compatible task inventions requires adjudication before treating model false negatives as errors. A third 40/60 implicit-bipedal test has now been constructed (see `samples/semantic_challenge_100/`), but its labeling definition is broader than the current strict prompt and a basic biped/non-exoskeleton keyword rule reaches 94% accuracy. Decide the intended relevance policy, independently adjudicate labels, then compare without tuning on the test set. **New 2026-10-31 evidence (still open):** The distinct 40/60 keyword-blind semantic holdout was run at 0.5: 38 TP / 56 TN / 4 FP / 2 FN relative to AI-provisional labels (94% accuracy, 95% recall, 90.48% precision), with six category-concentrated disagreements (nonhuman biped vs whole-body control). These results narrow the next work to adjudicating those cases and aligning task-oriented positives with the current strict humanoid-link criterion; they do not establish deployment-valid prevalence precision or threshold calibration.
